## 👨‍💻 About me

I'm a **DevOps / Cloud / Platform Engineer** based in Brasília, Brazil, focused on infrastructure automation, cloud platforms, identity and production environments.

My day-to-day work involves **Microsoft Azure, Entra ID, Intune, Microsoft 365 and PowerShell**, combined with infrastructure and DevOps technologies such as **Terraform, Docker, Kubernetes, CI/CD, Linux and Git**.

I enjoy taking infrastructure from manual operations to **versioned, repeatable and automated workflows**, with an emphasis on security, maintainability, troubleshooting and operational reliability.

# 🚀 Featured DevOps Projects

These repositories are public labs designed to demonstrate architecture and engineering practices.

Production environments, credentials and tenant-specific configuration remain private.

### ☸️ [Azure AKS Platform](https://github.com/IranRibeiro55/azure-aks-platform)

> Azure Kubernetes platform provisioned with Infrastructure as Code.

**What it demonstrates**

* Azure Virtual Network
* Azure Kubernetes Service — AKS
* Azure Container Registry — ACR
* Azure Key Vault
* Terraform
* GitHub Actions
* Terraform formatting and validation
* Azure authentication using OIDC
* Secretless CI/CD authentication architecture

**Stack:** `Azure` `AKS` `Terraform` `GitHub Actions` `OIDC` `Key Vault`

---

### 🔐 [GitHub OIDC → Azure](https://github.com/IranRibeiro55/github-oidc-azure)

> Passwordless authentication between GitHub Actions and Microsoft Azure.

Implements Azure identity federation using:

* User Assigned Managed Identity
* Federated Identity Credentials
* OpenID Connect — OIDC
* GitHub Actions
* Azure RBAC

The goal is to eliminate long-lived client secrets from CI/CD authentication.

**Stack:** `Azure` `Entra ID` `OIDC` `GitHub Actions` `Terraform`

---

### 🪪 [Hybrid Identity Lab](https://github.com/IranRibeiro55/hybrid-identity-lab)

> Architecture and documentation for a hybrid Microsoft identity environment.

Covers concepts including:

* Microsoft Entra ID
* Active Directory
* Microsoft Intune
* Conditional Access
* Windows Autopilot
* Break-glass accounts
* Hybrid identity architecture
* Security and operational documentation

**Stack:** `Entra ID` `Intune` `Active Directory` `Microsoft 365`

---

### ⚡ [Entra & Intune Operations](https://github.com/IranRibeiro55/entra-intune-ops)

> PowerShell automation for Microsoft Entra ID and Intune operations.

Read-only operational scripts using Microsoft Graph for:

* Directory role inventory
* Intune compliance status
* Stale device discovery
* Conditional Access inventory
* Environment visibility

**Stack:** `PowerShell` `Microsoft Graph` `Entra ID` `Intune`

---

### 🤖 [BIA-SHELL](https://github.com/IranRibeiro55/BIA-SHELL)

> PowerShell assistant for Windows support and infrastructure operations.

Features include:

* Machine diagnostics
* System information
* Operational playbooks
* Azure authentication
* Support workflow automation
* Portuguese / English / Spanish support

**Stack:** `PowerShell` `Windows` `Azure` `Automation`
